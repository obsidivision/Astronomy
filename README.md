# 천구와 행성의 겉보기 운동 시뮬레이터

`astronomy-sim.html` 하나로 끝나는 오프라인 천문 시뮬레이터입니다.
지구과학 Ⅲ-1 태양계 천체, 01. 태양계 행성의 겉보기 운동 학습지 00 ~ 04 에 맞추어 만들었습니다.

## 쓰는 법

파일을 내려받아 두 번 누르면 됩니다. 인터넷 연결, 설치, 서버가 모두 필요 없습니다.
바깥에서 불러오는 스크립트, 글꼴, 그림이 하나도 없고 브라우저 저장소도 쓰지 않습니다.

## 구성

| 탭 | 내용 |
|---|---|
| 1 | 천구와 지평좌표계 (방위각, 고도, 천정거리, 일주운동, 주극성 출몰성 전몰성) |
| 2 | 적도좌표계와 황도 (적경, 적위, 연주운동, 절기, 낮의 길이) |
| 3 | 행성의 겉보기 운동 (순행, 역행, 유, 회합주기) |
| 4 | 위치 관계와 위상 (내합 외합 최대이각 / 합 충 동구 서구, 시지름, 관측 가능 시간) |
| 5 | 문제 풀이 (학습지 문항 + 랜덤 자가 점검) |

## 자체 검증

`v` 키를 누르거나 오른쪽 위의 검증 단추를 누르면 81가지 검증 항목이 나옵니다.
기대값은 화면에 박아 넣은 상수가 아니라 계산 엔진에서 다시 구한 값과 비교합니다.
브라우저 콘솔에도 결과가 찍힙니다.

## 모형의 한계

- 궤도는 원궤도 근사입니다. 이심률은 넣지 않았습니다.
- 궤도경사는 실제 값을 그대로 씁니다. 이것을 0으로 두면 역행 경로가 직선이 되어 버립니다.
- 태양은 황도를 균일하게 (하루 0.9856도) 움직입니다. 그래서 춘분 3월 21일, 하지 6월 21일은 맞지만
  추분과 동지는 실제보다 2 ~ 3일 이릅니다.
- 낮의 길이는 기하학적 계산입니다. 대기 굴절과 태양의 시반경은 넣지 않았습니다.
